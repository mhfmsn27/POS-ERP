Kepatuhan Pajak & e-Faktur DJP

Modul kepatuhan perpajakan Indonesia resmi: kalkulasi PPN 11%, pemotongan PPh Pasal 21/23/Final UMKM, rekapitulasi Faktur Pajak Masukan/Keluaran, serta ekspor data format XML resmi untuk aplikasi e-Faktur Direktorat Jenderal Pajak (DJP).

Ekspor XML e-Faktur DJP

Anda dapat mengekspor faktur penjualan B2B dan transaksi PKP langsung menjadi format XML skema resmi DJP:

1
Isi Data NPWP / NIK Pelanggan
Pastikan data Nomor Pokok Wajib Pajak (NPWP 15/16 digit) dan alamat resmi pelanggan terisi pada master kontak.
2
Pilih Transaksi & Generate XML
Masuk ke menu Laporan Pajak → e-Faktur Export → Pilih rentang masa pajak → Klik Download XML DJP.
3
Import ke Aplikasi e-Faktur Desktop DJP
Buka aplikasi e-Faktur DJP → Pilih menu Impor Faktur Pajak Keluaran → Seluruh data langsung terunggah tanpa error skema.

Rekapitulasi SPT Masa PPN (PPN Kurang/Lebih Bayar)

Sistem menghitung posisi PPN bulanan secara otomatis:

Formula PPN Terutang
PPN Kurang/Lebih Bayar = Total PPN Keluaran (Penjualan) - Total PPN Masukan (Pembelian Supplier)
