Import & Export Massal Data (Excel / CSV)

Panduan migrasi data massal (*Bulk Data Import/Export*) dari sistem lama ke POSHUB. Mendukung template Excel siap pakai untuk ribuan produk, varian, pelanggan, supplier, saldo awal akun akuntansi, dan rekapitulasi SPT Masa Pajak.

3 Langkah Mudah Import Data Excel

1
Unduh File Template Resmi (.xlsx)
Masuk ke menu modul yang dituju (misal: Produk → Import Excel) → Klik Download Template Format.
2
Isi Data Sesuai Kolom Panduan
Salin data produk atau pelanggan Anda ke dalam template. Pastikan kolom wajib seperti Kode SKU, Nama Produk, dan Harga Jual terisi dengan benar.
3
Unggah File & Validasi Instan
Upload file Excel → Sistem memvalidasi data dalam hitungan detik (*Chunk Import 500 baris/detik*) → Seluruh produk langsung aktif di sistem.

Modul yang Mendukung Import / Export Massal

Nama Modul Format File Cakupan Data yang Diimpor
Katalog Produk & Varian .xlsx / .csv Nama, Barcode, Kategori, Merek, Harga Beli/Jual, Satuan UOM, dan Stok Awal.
Pelanggan & Supplier .xlsx / .csv Nama Kontak, No WhatsApp, Email, Alamat, NPWP, Plafon Kredit B2B.
Bagan Akun & Saldo Awal (COA) .xlsx Nomor Akun, Nama Akun, Klasifikasi Akun, dan Saldo Awal Debit/Kredit.
Faktur Pajak SPT DJP .xml / .csv Faktur Pajak Masukan & Keluaran kompatibel dengan aplikasi resmi DJP.
