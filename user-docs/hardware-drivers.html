2. Kasir POS & Smart Hardware

Hardware Drivers & Thermal Printing

Panduan integrasi perangkat keras kasir: printer thermal ESC/POS Bluetooth 58mm & 80mm, pemindai barcode USB/Kamera GPU, laci kasir otomatis (*Cash Drawer RJ11*), dan terminal POS Android pintar (Sunmi & iMin).

Direct Web Bluetooth Thermal Printing

POSHUB mendukung pencetakan struk langsung dari browser via Web Bluetooth API tanpa perlu menginstal aplikasi pihak ketiga (*Raw ESC/POS Driver*):

Printer 58mm & 80mm
Otomatis menyesuaikan lebar karakter (32 karakter untuk 58mm dan 48 karakter untuk 80mm).
Chunk Buffer Protection
Byte stream dipecah dalam paket 100-byte untuk mencegah buffer overflow pada printer thermal mini portabel.
Buka Laci Kasir (RJ-11)
Mengirim sinyal pulsa ESC p 0 25 250 secara otomatis setelah transaksi selesai untuk membuka laci kasir.
Auto Paper Cutter
Mengirim perintah potong kertas otomatis (GS V 66 0) pada printer thermal 80mm yang mendukung auto-cutter.

Hardware Bridge API (JavaScript)

Driver JavaScript global yang tersedia pada antarmuka kasir:

JavaScript Console API
// 1. Hubungkan ke Printer Bluetooth
await window.PoshubBluetoothPrinter.connect();

// 2. Kirim Text Cetak & Potong Kertas
await window.PoshubBluetoothPrinter.printFormattedReceipt({
  storeName: 'POSHUB OFFICIAL STORE',
  invoiceNo: 'INV-20260829-001',
  items: [...],
  total: 150000
});

// 3. Pemicu Buka Laci Kasir RJ-11
await window.PoshubBluetoothPrinter.openCashDrawer();

Dukungan Terminal POS Sunmi & iMin

Untuk perangkat Android All-in-One (Sunmi V2 Pro, Sunmi T2, iMin D4), POSHUB secara otomatis mendeteksi objek window.sunmiPrinter atau window.iminPrinter dan mengalihkan pencetakan ke hardware printer internal berkecepatan tinggi.
