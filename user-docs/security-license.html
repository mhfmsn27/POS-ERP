Sistem Lisensi 1-Domain Kriptografis (RSA-2048)

Arsitektur proteksi lisensi untuk model bisnis Jual Lepas (Open Codebase). Source code PHP/Laravel tetap 99% bersih dan bebas dikustomisasi oleh pembeli, namun aplikasi terkunci kuat secara matematis pada satu domain resmi dan tidak dapat di-bypass oleh AI ataupun cracking tools.

Prinsip Kriptografi Kunci Asimetris (RSA-2048)

1. Private Key (Hanya Author)
Tersimpan aman di komputer author. Digunakan untuk menandatangani (*Digital Signature*) nama domain dan kunci lisensi.
2. Public Key (Di Aplikasi)
Tertanam pada file config/license.php. HANYA bisa membaca dan memverifikasi tanda tangan digital.
3. Cryptographic Logic Binding
Kunci lisensi mengikat token kalkulasi struk kasir dan laporan laba rugi. Jika middleware dimatikan paksa, kalkulasi transaksi otomatis rusak.
4. Localhost Whitelist (100% Free)
Bebas uji coba di localhost, 127.0.0.1, dan *.test tanpa batasan.

Cara Menerbitkan Lisensi Klien Baru (Artisan CLI)

Jalankan perintah ini di komputer author untuk menghasilkan baris lisensi baru:

Terminal Command (Author Only)
php artisan license:generate domainklien.com --client="Nama Klien PT ABC"

Salin hasil output CSV ke baris baru Google Spreadsheet lisensi pusat Anda.
