Dokumentasi Pengembang & REST API

Antarmuka pemrograman aplikasi (*Application Programming Interface*) standar RESTful JSON untuk integrasi sistem pihak ketiga, marketplace, ERP eksternal, dan aplikasi mobile custom dengan autentikasi Laravel Sanctum Bearer Token.

Autentikasi API (Bearer Token)

Setiap permintaan API harus menyertakan header otentikasi:

HTTP Headers
Authorization: Bearer 1|xxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx
Accept: application/json
Content-Type: application/json

Daftar Endpoint Utama

Method Endpoint URL Deskripsi & Fungsi
POST /api/auth/login Autentikasi pengguna & mendapatkan Bearer Token Sanctum.
GET /api/products Mengambil daftar produk, varian, dan stok fisik per cabang.
POST /api/pos/transactions Membuat transaksi penjualan kasir baru & pemotongan stok otomatis.
GET /api/customers Mengambil data pelanggan, saldo poin, dan tier VIP.
GET /api/license/status Memeriksa status validitas lisensi domain aktif server.
