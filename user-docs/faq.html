Operasional Kasir & Hardware

Bagaimana jika printer Bluetooth tidak terdeteksi saat menekan tombol cetak?
Pastikan Bluetooth di komputer/tablet sudah dalam posisi aktif (ON) dan printer thermal dalam keadaan menyala. Di browser Chrome/Edge, klik ikon gembok di sebelah URL → pastikan izin Bluetooth diatur ke Allow (Izinkan).
Apakah kasir tetap bisa bertransaksi jika koneksi internet toko terputus?
Ya, teknologi PWA 2.0 POSHUB secara otomatis menyimpan transaksi di IndexedDB lokal browser. Begitu koneksi internet pulih, sistem akan melakukan sinkronisasi otomatis ke server pusat tanpa ada data yang hilang.

Sistem Lisensi 1-Domain

Mengapa muncul layar 'Akses Lisensi Domain Terkunci'?
Layar lock screen muncul jika domain yang sedang digunakan belum terdaftar di Google Spreadsheet lisensi pusat atau signature RSA-2048 tidak cocok. Hubungi author untuk mendaftarkan domain baru Anda via perintah php artisan license:generate.
Apakah saya bisa mengembangkan aplikasi di localhost tanpa internet?
Ya 100%! Domain localhost, 127.0.0.1, dan domain lokal *.test di-whitelist secara otomatis dan bebas dari pemeriksaan lisensi.
