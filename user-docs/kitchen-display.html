Kitchen Display System (KDS) & Bar Ticket

Sistem tampilan pesanan dapur dan bar tanpa kertas (*Paperless Kitchen Order Ticket*). Pesanan dari kasir otomatis dipisahkan antara pos dapur makanan dan pos bar minuman dengan indikator waktu pembuatan dan peringatan keterlambatan visual.

Alur Kerja Dapur Digital

Auto Station Routing
Item makanan otomatis diarahkan ke layar KDS Kitchen, sedangkan minuman diarahkan ke layar KDS Bar/Beverage.
Color-Coded Time Alerts
Kartu tiket berubah warna: Hijau (0–5 mnt), Kuning (5–10 mnt), dan Merah Berkedip (>15 mnt) jika pesanan melewati standar SLA.
1-Click Status Update
Koki cukup menyentuh kartu untuk mengubah status: Pending → Cooking → Ready to Serve → Completed.
Nomor Meja & Catatan Koki
Menampilkan nomor meja dan catatan khusus pelanggan (misal: "Pedas level 5, Tanpa Bawang").

Cara Mengakses Layar KDS

Buka browser pada tablet atau monitor Smart TV di area dapur dan akses URL:

URL Layar KDS Dapur
https://poshub.internatechtion.my.id/pos/kitchen-display

REST API Status Tiket Dapur

Aplikasi pihak ketiga atau monitor Android dapat mengupdate status tiket via API:

POST /api/kds/tickets/{id}/status
// Request Body JSON
{
  "status": "ready" // Pilihan: "cooking", "ready", "completed", "cancelled"
}
