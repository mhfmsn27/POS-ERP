Pencadangan Otomatis (Auto Backup) & Pemeliharaan Sistem

Sistem pencadangan basis data otomatis terjadwal (*Scheduled Database Dump*), kompresi arsip ZIP, pengiriman cadangan ke cloud storage (Google Drive / S3 / Wasabi), serta pembersihan cache dan log sistem untuk performa server maksimal.

Pencadangan Database Manual via CLI

Jalankan perintah ini di terminal server VPS Anda:

Bash Command (VPS Terminal)
cd /var/www/poshub
php artisan backup:run --only-db

Pembersihan Cache & Optimasi Kecepatan (Optimizer)

Jalankan perintah pembersihan dan kompilasi cache jika melakukan perubahan konfigurasi:

Bash Command (Optimize Production)
# 1. Bersihkan Seluruh Cache Lama
php artisan optimize:clear

# 2. Kompilasi Cache Produksi Super Cepat
php artisan config:cache
php artisan route:cache
php artisan view:cache
