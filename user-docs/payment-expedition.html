6. E-Commerce Omnichannel

Integrasi Payment Gateway & Cek Ongkir Otomatis

Panduan integrasi gerbang pembayaran otomatis (*Payment Gateway Snap/Core API*) untuk menerima pembayaran QRIS, Virtual Account Bank (BCA, Mandiri, BNI, BRI), E-Wallet (GoPay, OVO, ShopeePay), serta kalkulasi ongkos kirim real-time kurir nasional via RajaOngkir API.

Konfigurasi Midtrans Payment Gateway

Masukkan kredensial Midtrans Production atau Sandbox ke dalam file .env Anda:

Konfigurasi Midtrans .env
MIDTRANS_SERVER_KEY=SB-Mid-server-xxxxxxxxxxxx
MIDTRANS_CLIENT_KEY=SB-Mid-client-xxxxxxxxxxxx
MIDTRANS_IS_PRODUCTION=false
MIDTRANS_IS_SANITIZED=true
MIDTRANS_IS_3DS=true

Konfigurasi Ekspedisi & RajaOngkir API

Mendukung pengecekan ongkos kirim otomatis hingga tingkat kecamatan/kelurahan untuk kurir: JNE, J&T, SiCepat, POS Indonesia, Anteraja, dan Tiki.

Konfigurasi RajaOngkir .env
RAJAONGKIR_API_KEY=your_rajaongkir_api_key_here
RAJAONGKIR_PACKAGE_TYPE=pro # Pilihan: starter, basic, pro
RAJAONGKIR_ORIGIN_CITY_ID=152 # ID Kota Asal Pengiriman Gudang Toko
