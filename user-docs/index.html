Pengantar & Arsitektur Sistem

Selamat datang di dokumentasi resmi POSHUB ACCOUNTING & ERP Enterprise Edition (v3.5). Platform terpadu Point of Sale (POS), Akuntansi Standar PSAK, Manajemen Rantai Pasok, E-Commerce Terintegrasi, dan Sistem Lisensi Kriptografis 1-Domain.

Arsitektur Teknologi

POSHUB dibangun di atas arsitektur monolitik modern berkinerja tinggi (*High Performance Hybrid Architecture*) dengan pemisahan concern yang terstruktur rapi:

Backend Engine
Laravel Framework PHP 8.x dengan Eloquent ORM, Service Layer Pattern, dan Repository Pattern.
Frontend POS & SPA
Vue.js interaktif berkecepatan tinggi dengan state management terpusat untuk kelancaran transaksi kasir.
PWA & Hardware Native
Service Worker Offline Sync, Capacitor Native Mobile Bridge, dan Web Bluetooth ESC/POS Direct Print.
Keamanan Lisensi RSA
Asymmetric Cryptography RSA-2048 dengan Cryptographic Logic Binding pada kalkulasi transaksi.

Panduan Memulai Cepat (Localhost)

1
Kloning & Konfigurasi File .env
Salin file .env.example menjadi .env dan sesuaikan kredensial database lokal:
Terminal
cp .env.example .env
php artisan key:generate
2
Jalankan Migrasi Database & Seeder Master
Inisialisasi seluruh tabel dan data awal sistem:
Terminal
php artisan migrate --seed
3
Jalankan Server Lokal
Jalankan server PHP bawaan Laravel:
Terminal
php artisan serve
