1. Memulai & Fondasi

Setup VPS Multi-Tenant (Domainesia & Rumahweb)

Panduan langkah demi langkah memasang POSHUB ACCOUNTING pada VPS Linux yang sudah aktif menjalankan aplikasi CRM. Seluruh komponen (folder aplikasi, database, virtual host Nginx, worker, dan sertifikat SSL) dibuat 100% terisolasi mandiri tanpa mengganggu layanan CRM yang sedang berjalan.

1. Arsitektur Isolasi 1 VPS Bersama

Komponen Sistem CRM Eksisting (Tetap Aktif) POSHUB Baru (Terisolasi)
Domain / Host 2 Domain CRM yang sudah ada poshub.internatechtion.my.id
Direktori Project /var/www/crmhub (atau lokasi lama) /var/www/poshub (Folder Khusus)
Database MySQL crm_database (TIDAK TERSENTUH) poshub_accounting (Database Baru)
Nginx Virtual Host Vhost lama CRM sites-available/poshub.internatechtion.my.id
SSL Certificate Certbot SSL lama Let's Encrypt SSL Baru

2. Setup DNS Record di Rumahweb

1
Login ke ClientZone Rumahweb
Buka clientzone.rumahweb.com → Masuk ke menu Domains → Pilih domain internatechtion.my.id → Klik DNS Management (Zone Editor).
2
Tambahkan A-Record Subdomain 'poshub'
Buat A-Record baru dengan Nama: poshub, Target IP: IP_VPS_DOMAINESIA, TTL: 14400.
3
Uji Propagasi DNS
Jalankan perintah ping di terminal: ping poshub.internatechtion.my.id. Pastikan merespons ke IP VPS Anda.

3. Pembuatan Database MySQL Terpisah

Login ke SSH VPS Domainesia Anda dan buat database khusus POSHUB:

SQL Commands (MySQL Console)
CREATE DATABASE poshub_accounting CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci;
CREATE USER 'poshub_user'@'localhost' IDENTIFIED BY 'PasswordKuatPoshub2026!';
GRANT ALL PRIVILEGES ON poshub_accounting.* TO 'poshub_user'@'localhost';

6. Nginx Server Block & SSL HTTPS

/etc/nginx/sites-available/poshub.internatechtion.my.id
server {
    listen 80;
    server_name poshub.internatechtion.my.id;
    root /var/www/poshub/public;

    index index.php index.html;
    charset utf-8;
    client_max_body_size 64M;

    location / {
        try_files $uri $uri/ /index.php?$query_string;
    }

    location ~ \.php$ {
        fastcgi_pass unix:/var/run/php/php8.1-fpm.sock;
        fastcgi_param SCRIPT_FILENAME $realpath_root$fastcgi_script_name;
        include fastcgi_params;
    }

    location ~ /\.(?!well-known).* {
        deny all;
    }
}

Aktifkan vhost dan pasang SSL Let's Encrypt gratis:

Terminal
sudo ln -s /etc/nginx/sites-available/poshub.internatechtion.my.id /etc/nginx/sites-enabled/
sudo nginx -t && sudo systemctl reload nginx
sudo certbot --nginx -d poshub.internatechtion.my.id
