1. Memulai & Fondasi

Setup VPS Multi-Tenant (Domainesia & Rumahweb)

Panduan langkah demi langkah memasang POSHUB ACCOUNTING pada VPS Linux Ubuntu yang sudah aktif menjalankan aplikasi CRM. Seluruh komponen (folder aplikasi, dependencies, database MySQL, virtual host Nginx, worker, dan sertifikat SSL) dibuat 100% terisolasi mandiri tanpa mengganggu layanan CRM yang sedang berjalan.

1. Arsitektur Isolasi 1 VPS Bersama

Komponen Sistem CRM Eksisting (Tetap Aktif) POSHUB Baru (Terisolasi)
Domain / Host 2 Domain CRM yang sudah ada poshub.internatechtion.my.id
Direktori Project /var/www/crmhub (atau lokasi lama) /var/www/poshub (Folder Khusus)
Dependencies Node.js / PM2 Backend PHP 8.2-FPM & Composer 2.x
Database MySQL crm_database (TIDAK TERSENTUH) poshub_accounting (Database Baru)
Nginx Virtual Host Vhost lama CRM sites-available/poshub.internatechtion.my.id
SSL Certificate Certbot SSL lama Let's Encrypt SSL Baru

2. Instalasi Dependencies Dasar (PHP 8.2, MySQL, Nginx, Composer, Node.js)

Jalankan perintah berikut di terminal SSH VPS Ubuntu Anda:

1
Update Paket Sistem & Pasang Nginx
Terminal SSH
sudo apt update && sudo apt upgrade -y
sudo apt install -y curl wget git unzip zip software-properties-common ufw ca-certificates lsb-release gnupg2 nginx
sudo systemctl enable nginx
sudo systemctl start nginx
2
Pasang PHP 8.2 & Ekstensi Lengkap Laravel
Terminal SSH
sudo add-apt-repository ppa:ondrej/php -y
sudo apt update
sudo apt install -y php8.2-fpm php8.2-cli php8.2-mysql php8.2-mbstring php8.2-xml php8.2-bcmath php8.2-curl php8.2-gd php8.2-zip php8.2-intl php8.2-soap php8.2-imagick php8.2-opcache php8.2-redis
sudo systemctl enable php8.2-fpm
sudo systemctl start php8.2-fpm
3
Pasang Composer 2.x Global, Node.js & MySQL Server
Terminal SSH
# Composer 2.x
curl -sS https://getcomposer.org/installer | php
sudo mv composer.phar /usr/local/bin/composer
sudo chmod +x /usr/local/bin/composer

# MySQL Server & Node.js 20.x
curl -fsSL https://deb.nodesource.com/setup_20.x | sudo -E bash -
sudo apt install -y mysql-server nodejs certbot python3-certbot-nginx supervisor
sudo systemctl enable mysql
sudo systemctl start mysql

3. Setup DNS Record di Rumahweb

1
Login ke ClientZone Rumahweb
Buka clientzone.rumahweb.com → Masuk ke menu Domains → Pilih domain internatechtion.my.id → Klik DNS Management (Zone Editor).
2
Tambahkan A-Record Subdomain 'poshub'
Buat A-Record baru dengan Nama: poshub, Target IP: IP_VPS_DOMAINESIA, TTL: 14400.
3
Uji Propagasi DNS
Jalankan perintah ping di terminal: ping poshub.internatechtion.my.id. Pastikan merespons ke IP VPS Anda.

4. Pembuatan Database MySQL Terpisah

Login ke SSH VPS Domainesia Anda dan buat database khusus POSHUB:

SQL Commands (MySQL Console)
CREATE DATABASE poshub_accounting CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci;
CREATE USER 'poshub_user'@'localhost' IDENTIFIED BY 'PasswordKuatPoshub2026!';

5. Upload & Izin Akses Folder

Buat direktori dan atur perizinan hak akses web server:

Bash Command (VPS SSH)
sudo mkdir -p /var/www/poshub
sudo chown -R $USER:$USER /var/www/poshub
cd /var/www/poshub

# Clone project atau upload ZIP file:
git clone https://github.com/username/poshub-accounting.git .

# Install Dependensi Composer & Buat Key
composer install --no-dev --optimize-autoloader
php artisan key:generate

# Migrasi Database Beserta Seeder Demo Lengkap
php artisan migrate --seed --force

# Storage Link & Cache Optimasi Produksi
php artisan storage:link
php artisan config:cache
php artisan route:cache
php artisan view:cache

# Hak Akses Folder Storage
sudo chown -R www-data:www-data /var/www/poshub/storage /var/www/poshub/bootstrap/cache
sudo chmod -R 775 /var/www/poshub/storage /var/www/poshub/bootstrap/cache

6. Konfigurasi Nginx Server Block

Buat file virtual host: sudo nano /etc/nginx/sites-available/poshub.internatechtion.my.id

Nginx Configuration
server {
    listen 80;
    listen [::]:80;
    server_name poshub.internatechtion.my.id;

    root /var/www/poshub/public;
    index index.php index.html;

    client_max_body_size 50M;

    location / {
        try_files $uri $uri/ /index.php?$query_string;
    }

    location ~ \.php$ {
        include snippets/fastcgi-php.conf;
        fastcgi_pass unix:/var/run/php/php8.2-fpm.sock;
        fastcgi_param SCRIPT_FILENAME $realpath_root$fastcgi_script_name;
        include fastcgi_params;
        fastcgi_read_timeout 300;
    }

    location ~* \.(jpg|jpeg|png|gif|ico|css|js|svg|webp|woff2)$ {
        expires 30d;
        add_header Cache-Control "public, no-transform";
        access_log off;
    }

    location ~ /\.(?!well-known).* {
        deny all;
    }
}

Aktifkan konfigurasi Nginx dan reload layanan:

Bash Command
sudo ln -s /etc/nginx/sites-available/poshub.internatechtion.my.id /etc/nginx/sites-enabled/
sudo nginx -t
sudo systemctl reload nginx

7. Pasang Sertifikat SSL HTTPS Let's Encrypt

Bash Command (Certbot)
sudo certbot --nginx -d poshub.internatechtion.my.id
