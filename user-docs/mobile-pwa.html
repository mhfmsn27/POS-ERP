7. Mobile, Keamanan & Referensi

PWA 2.0 & Native Mobile App (Android / iOS)

Arsitektur Progressive Web App (PWA) generasi 2.0 dengan Service Worker canggih untuk sinkronisasi transaksi saat internet terputus (*Offline Background Sync*), serta wrapper native Capacitor untuk kompilasi menjadi file instalasi APK Android dan IPA iOS.

Arsitektur Offline POS PWA 2.0

IndexedDB Transaction Queue
Jika jaringan internet kasir tiba-tiba putus, transaksi kasir tetap dapat diproses dan disimpan di database lokal browser (*IndexedDB*).
Background Auto-Sync
Saat koneksi internet kembali online, Service Worker secara otomatis mengirim antrian transaksi ke server pusat tanpa intervensi kasir.
Install to Homescreen
Aplikasi dapat diinstal langsung ke layar utama Android/iOS/Windows Desktop seperti aplikasi native tanpa melalui Play Store.
Web Push Notifications
Pemberitahuan push instan untuk pesanan baru e-commerce, persetujuan PO, dan peringatan stok minimum.

Kompilasi APK Android via Capacitor

Langkah membungkus PWA menjadi file APK Android mandiri:

Terminal (Capacitor Build)
# 1. Inisialisasi Capacitor
npx cap init "POSHUB Enterprise" "com.poshub.app"

# 2. Tambahkan Platform Android
npx cap add android

# 3. Sinkronisasi Aset Web
npx cap sync

# 4. Buka di Android Studio & Generate Signed APK / AAB
npx cap open android
