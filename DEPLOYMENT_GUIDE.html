Panduan Deployment POSHUB ACCOUNTING

Langkah Demi Langkah Deployment VPS

1
Perbarui Server & Pasang Paket Dasar
Masuk ke terminal SSH VPS sebagai root/sudoer:
Bash Terminal
sudo apt update && sudo apt upgrade -y
sudo apt install -y software-properties-common curl git unzip zip nginx supervisor certbot python3-certbot-nginx
2
Instal PHP 8.1 & Seluruh Ekstensi
Tambahkan repositori PPA Ondrej PHP dan instal PHP 8.1 FPM:
Bash Terminal
sudo add-apt-repository ppa:ondrej/php -y
sudo apt update
sudo apt install -y php8.1-fpm php8.1-cli php8.1-common php8.1-mysql php8.1-zip \
                    php8.1-gd php8.1-mbstring php8.1-curl php8.1-xml php8.1-bcmath

# Instal Composer Global
curl -sS https://getcomposer.org/installer | sudo php -- --install-dir=/usr/local/bin --filename=composer
3
Setup Basis Data MySQL
Buat basis data baru dan berikan hak akses penuh ke user lokal:
MySQL Console
sudo mysql -u root -p

-- Di dalam console MySQL:
CREATE DATABASE poshub_db CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci;
CREATE USER 'poshub_user'@'localhost' IDENTIFIED BY 'PasswordKuatAnda_123!';
GRANT ALL PRIVILEGES ON poshub_db.* TO 'poshub_user'@'localhost';
FLUSH PRIVILEGES;
EXIT;
4
Unggah Source Code & Konfigurasi .env
Letakkan source code pada direktori /var/www/poshub:
Bash Terminal
cd /var/www/poshub
cp .env.example .env
nano .env
Pastikan mengubah APP_ENV=production, APP_DEBUG=false, APP_URL=https://poshub.domainanda.com, serta parameter DB_* sesuai kredensial di Langkah 3.
5
Instal Dependensi, Migrasi & Permissions
Bash Terminal
# 1. Instal vendor Composer (Mode Produksi)
composer install --no-dev --optimize-autoloader

# 2. Generate App Key & Symlink Storage
php artisan key:generate --force
php artisan storage:link

# 3. Jalankan Migrasi & Enterprise Master Seeder
php artisan migrate --seed --force

# 4. Atur Hak Akses Direktori
sudo chown -R www-data:www-data /var/www/poshub
sudo find /var/www/poshub -type f -exec chmod 644 {} \;
sudo find /var/www/poshub -type d -exec chmod 755 {} \;
sudo chmod -R 775 /var/www/poshub/storage /var/www/poshub/bootstrap/cache
6
Konfigurasi Virtual Host Nginx & SSL Let's Encrypt
/etc/nginx/sites-available/poshub.conf
server {
    listen 80;
    server_name poshub.domainanda.com;
    root /var/www/poshub/public;

    add_header X-Frame-Options "SAMEORIGIN";
    add_header X-Content-Type-Options "nosniff";
    index index.php index.html;
    charset utf-8;

    client_max_body_size 50M;

    location / {
        try_files $uri $uri/ /index.php?$query_string;
    }

    location = /favicon.ico { access_log off; log_not_found off; }
    location = /robots.txt  { access_log off; log_not_found off; }

    error_page 404 /index.php;

    location ~ \.php$ {
        fastcgi_pass unix:/var/run/php/php8.1-fpm.sock;
        fastcgi_param SCRIPT_FILENAME $realpath_root$fastcgi_script_name;
        include fastcgi_params;
        fastcgi_hide_header X-Powered-By;
    }

    location ~ /\.(?!well-known).* {
        deny all;
    }
}
Aktifkan Virtual Host dan pasang SSL otomatis:
Bash Terminal
sudo ln -s /etc/nginx/sites-available/poshub.conf /etc/nginx/sites-enabled/
sudo nginx -t && sudo systemctl reload nginx

# Pasang SSL Otomatis
sudo certbot --nginx -d poshub.domainanda.com

Struktur Direktori Aman di Shared Hosting (cPanel)

Untuk keamanan maksimal, letakkan source code inti di luar public_html:

Struktur Folder cPanel
/home/username/
├── poshub/              <--- Letakkan seluruh berkas proyek di sini (kecuali folder public)
│   ├── app/
│   ├── config/
│   ├── database/
│   ├── .env
│   └── ...
└── public_html/         <--- Letakkan ISI folder public di sini
    ├── index.php
    ├── css/
    ├── js/
    ├── assets/
    └── .htaccess
1
Pilih PHP 8.1 di cPanel
Buka menu Select PHP Version di cPanel, pilih PHP 8.1 dan aktifkan ekstensi: bcmath, fileinfo, gd, intl, mbstring, mysqli, openssl, pdo_mysql, zip.
2
Buat Database MySQL di cPanel
Masuk ke menu MySQL Databases, buat database dan user baru, lalu berikan hak akses ALL PRIVILEGES.
3
Unggah File & Sesuaikan index.php
Buka file public_html/index.php, ubah path bootstrap menjadi:
public_html/index.php
require __DIR__.'/../poshub/vendor/autoload.php';
$app = require_once __DIR__.'/../poshub/bootstrap/app.php';
4
Jalankan Migrasi & Symlink Storage
Jika cPanel memiliki akses Terminal / SSH:
cPanel Terminal
cd /home/username/poshub
php artisan migrate --seed --force
php artisan storage:link

Supervisor (Antrean Background WhatsApp & Invoice)

Supervisor memastikan proses pengiriman WhatsApp digital receipt dan laporan shift Z-Report berjalan seketika di background tanpa membebani browser kasir.

/etc/supervisor/conf.d/poshub-worker.conf
[program:poshub-worker]
process_name=%(program_name)s_%(process_num)02d
command=php /var/www/poshub/artisan queue:work database --sleep=3 --tries=3 --max-time=3600
autostart=true
autorestart=true
stopasgroup=true
killasgroup=true
user=www-data
numprocs=2
redirect_stderr=true
stdout_logfile=/var/www/poshub/storage/logs/worker.log
stopwaitsecs=3600
Perintah Reload Supervisor
sudo supervisorctl reread
sudo supervisorctl update
sudo supervisorctl start poshub-worker:*

Task Scheduler (Cron Job)

Diperlukan untuk auto-pruning cadangan database lama (>30 hari) dan auto-reorder PO:

Crontab VPS (sudo crontab -u www-data -e) atau Menu Cron Job cPanel
* * * * * cd /var/www/poshub && php artisan schedule:run >> /dev/null 2>&1

Solusi Masalah Umum (Troubleshooting)

1. Halaman Putih Kosong (500 Error):
Jalankan chmod -R 775 storage bootstrap/cache dan chown -R www-data:www-data storage bootstrap/cache.
2. Gambar Logo & Produk 404 Not Found:
Pastikan symlink storage terhubung dengan menjalankan php artisan storage:link.
3. Akselerasi Performa Produksi:
Jalankan perintah berikut setelah deploy selesai:
php artisan config:cache && php artisan route:cache && php artisan view:cache
