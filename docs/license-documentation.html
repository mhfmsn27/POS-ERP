1. Overview & Arsitektur Lisensi

Sistem lisensi POSHUB dirancang khusus untuk mengakomodasi kebutuhan bisnis **Jual Lepas (*Buy-Out Model*)**. Pembeli memiliki akses penuh terhadap source code PHP, Blade view, Vue frontend, dan struktur database untuk menambah modul sendiri, namun aplikasi **tetap terkunci pada 1 domain resmi pembeli**.

Mengapa Sistem Ini Tidak Bisa Dibypass oleh AI atau Cracker?
Sistem menggunakan Kriptografi Kunci Asimetris (RSA-2048 / SHA-256). Aplikasi klien hanya memiliki Public Key untuk memvalidasi. Tanpa Private Key yang Anda pegang di komputer pusat, secara matematis mustahil bagi siapapun membuat tanda tangan digital yang sah untuk domain lain.
Karakteristik Penjelasan Status Keamanan
Model Kriptografi Kunci Asimetris RSA-2048 + Digital Signature SHA-256 ✅ Standar Militer (Uncrackable)
Hak Kustomisasi Pembeli Source code 99% terbuka (Tanpa ionCube / SourceGuardian) ✅ Bebas Dikembangkan Pembeli
Offline Grace Period Toleransi 7 hari operasional jika internet toko putus ⚡ Resiliensi Kasir Tinggi
Localhost Mode Bebas 100% tanpa lisensi di localhost / 127.0.0.1 ✅ 100% Unrestricted Dev

2. Panduan Setup Google Sheet Lisensi Pusat

Anda tidak memerlukan server database lisensi terpisah. Seluruh data lisensi klien dikelola melalui 1 file Google Spreadsheet yang aman dan mudah diedit kapan saja.

1
Buat Google Spreadsheet Baru
Buka Google Sheets dan buat dokumen baru bernama POSHUB Official Licenses.
2
Atur Header Kolom pada Baris 1
Tuliskan 4 judul kolom berikut di baris paling atas (Row 1):
  • Kolom A: Domain (contoh: tokosaya.com)
  • Kolom B: License_Key (contoh: POSHUB-2026-AB89EF01-7788)
  • Kolom C: RSA_Signature (Tanda tangan digital dari generator)
  • Kolom D: Client_Name (Nama pemilik/klien)
3
Bagikan Spreadsheet Sebagai Publik (Viewer)
Klik tombol Bagikan (Share) di kanan atas → ubah General Access menjadi "Anyone with the link can view" (Siapa saja yang memiliki link dapat melihat).
4
Salin Google Sheet ID
Ambil ID spreadsheet dari URL browser Anda:
URL CONTOH GOOGLE SHEET
https://docs.google.com/spreadsheets/d/1BxiMVs0XRA5nFMdKvBdBZjgmUUqptlbs74OgvE2upms/edit
ID yang disalin: 1BxiMVs0XRA5nFMdKvBdBZjgmUUqptlbs74OgvE2upms

3. Konfigurasi File .env

Tempelkan konfigurasi lisensi berikut ke dalam file .env pada server aplikasi:

.env (Environment Configuration) 
# ==========================================
# ENTERPRISE DOMAIN-LOCKED LICENSE SYSTEM
# ==========================================
# ID Google Sheet lisensi pusat milik Anda
LICENSE_SHEET_ID=1BxiMVs0XRA5nFMdKvBdBZjgmUUqptlbs74OgvE2upms

# Set false untuk produksi (hanya true untuk pengembang lokal)
ALLOW_ALL_LICENSE=false

# Durasi Cache Lisensi Lokal dalam Detik (Default: 21600 = 6 Jam)
LICENSE_CACHE_TTL=21600

# Masa Tenggang Offline Kasir dalam Detik (Default: 604800 = 7 Hari)
LICENSE_OFFLINE_GRACE_PERIOD=604800

4. Cara Menerbitkan Lisensi Pembeli Baru

Setiap kali ada klien/pembeli baru yang membeli aplikasi untuk domain mereka, Anda cukup menjalankan perintah Artisan di terminal komputer Anda:

Terminal Command 
php artisan license:generate tokosaya.com --client="PT Toko Maju Sejahtera"

5. Mode Localhost & Pengembangan (100% Bebas)

Sistem lisensi POSHUB memiliki fitur Zero-Friction Local Development. Pengembang atau pembeli dapat melakukan *coding*, menambah fitur, atau menjalankan unit test tanpa perlu internet atau lisensi pada domain-domain berikut:

  • localhost atau localhost:8000 / localhost:3000
  • 127.0.0.1 atau ::1
  • Ekstensi domain lokal: *.test, *.local, *.example
  • Ketika APP_ENV=local atau ALLOW_ALL_LICENSE=true di file .env.

6. Cryptographic Logic Binding & Digital Seal

Untuk memastikan lisensi tidak bisa di-bypass dengan sekadar menghapus baris kode middleware, sistem menerapkan Logic Binding:

  • Struk Cetak Kasir Thermal: Setiap struk termal 58mm & 80mm mencetak tanda tangan kriptografis SEAL: {CHECKSUM} yang dihitung langsung dari token lisensi yang sah.
  • Laporan Keuangan & Akuntansi (P&L): Ringkasan laba rugi departemen menghasilkan integrity_seal untuk menjamin keaslian data.

7. FAQ & Solusi Kendala

Pertanyaan / Masalah Penyebab Solusi
Layar menampilkan "Domain Belum Terlisensi" Domain belum dimasukkan di Google Sheet atau nama domain salah ketik. Pastikan nama domain di Google Sheet sama persis (tanpa www. atau https://). Setelah menambahkan baris di sheet, klik tombol "Cek Ulang Status Lisensi".
Internet toko mati mendadak Koneksi ISP toko terputus. Kasir tetap dapat bertransaksi normal berkat fitur 7-Day Offline Grace Period.
Ingin memindahkan lisensi ke domain baru Klien berganti domain utama. Generate lisensi baru dengan php artisan license:generate domainbaru.com lalu ubah baris di Google Sheet.
Bagaimana cara memaksa refresh cache lisensi? Cache lokal masih menyimpan status lama (6 jam). Jalankan request POST ke /api/license/refresh atau klik tombol Cek Ulang di layar lock screen.
