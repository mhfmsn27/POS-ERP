1. Arsitektur Isolasi Multi-Tenant (1 VPS Bersama)

Berikut perbandingan pemisahan komponen CRM eksisting vs POSHUB baru di dalam VPS yang sama:

Aplikasi CRM Eksisting (Tetap Berjalan Aman)
  • Domain: 2 Domain CRM yang sudah ada
  • Folder Path: /var/www/crmhub (atau lokasi lama)
  • Services: PM2 Node.js (Port 8999 Omnichannel & WA-Gateway)
  • Database: crm_database (TIDAK AKAN TERSENTUH)
Aplikasi POSHUB Baru (Terisolasi Mandiri)
  • Domain: poshub.internatechtion.my.id
  • Folder Path: /var/www/poshub (Folder Khusus Baru)
  • Services: Nginx + PHP 8.2-FPM + Supervisor Queue
  • Database: poshub_accounting (Database MySQL Baru Terpisah)

2. Instalasi Dependencies Dasar (PHP 8.2, MySQL, Nginx, Composer, Node.js)

Jika VPS Anda baru diinstall atau belum memiliki dependensi Laravel yang lengkap, jalankan perintah berikut secara berurutan:

1
Update Sistem & Package Manager Base Tools
Perbarui repository paket Ubuntu dan pasang utilitas dasar:
Terminal VPS (SSH) 
sudo apt update && sudo apt upgrade -y
sudo apt install -y curl wget git unzip zip software-properties-common ufw ca-certificates lsb-release gnupg2
2
Instalasi Web Server Nginx
Pastikan Web Server Nginx terpasang dan berjalan:
Terminal VPS (SSH) 
sudo apt install -y nginx
sudo systemctl enable nginx
sudo systemctl start nginx
3
Instalasi PHP 8.2 & Ekstensi Lengkap Laravel / POSHUB
Pasang PHP 8.2 beserta seluruh modul ekstensi yang dibutuhkan:
Terminal VPS (SSH) 
sudo add-apt-repository ppa:ondrej/php -y
sudo apt update
sudo apt install -y php8.2-fpm php8.2-cli php8.2-mysql php8.2-mbstring php8.2-xml php8.2-bcmath php8.2-curl php8.2-gd php8.2-zip php8.2-intl php8.2-soap php8.2-imagick php8.2-opcache php8.2-redis
sudo systemctl enable php8.2-fpm
sudo systemctl start php8.2-fpm
Rekomendasi Konfigurasi php.ini:
Buka file sudo nano /etc/php/8.2/fpm/php.ini dan pastikan parameter berikut telah disesuaikan:
upload_max_filesize = 64M • post_max_size = 64M • memory_limit = 512M • max_execution_time = 300
4
Instalasi Composer 2.x (Global)
Pasang dependency manager Composer resmi secara global:
Terminal VPS (SSH) 
curl -sS https://getcomposer.org/installer | php
sudo mv composer.phar /usr/local/bin/composer
sudo chmod +x /usr/local/bin/composer
composer --version
5
Instalasi Database Server MySQL
Pasang MySQL Server jika belum terinstall di VPS:
Terminal VPS (SSH) 
sudo apt install -y mysql-server
sudo systemctl enable mysql
sudo systemctl start mysql
6
Instalasi Node.js 20.x & Certbot SSL
Pasang Node.js untuk build asset frontend dan Certbot untuk SSL Let's Encrypt:
Terminal VPS (SSH) 
# Node.js 20.x LTS
curl -fsSL https://deb.nodesource.com/setup_20.x | sudo -E bash -
sudo apt install -y nodejs certbot python3-certbot-nginx supervisor

3. Setup DNS Record di Rumahweb

Arahkan subdomain poshub pada domain internatechtion.my.id ke alamat IP Publik VPS Domainesia Anda:

1
Login ke ClientZone Rumahweb
Buka clientzone.rumahweb.com → Masuk ke menu Domains → Pilih domain internatechtion.my.id → Klik DNS Management (Zone Editor).
2
Tambahkan A-Record Subdomain 'poshub'
Buat DNS Record baru dengan parameter berikut:
Record Type Host / Subdomain Name Target / IP Address TTL
A Record poshub 103.xxx.xxx.xxx (Masukkan IP Publik VPS Domainesia Anda) 14400 (atau Auto)
3
Verifikasi Propagasi DNS
Tunggu 2–10 menit, lalu uji di terminal komputer Anda apakah domain sudah terhubung ke IP VPS:
Command Prompt / Terminal 
ping poshub.internatechtion.my.id

4. Pembuatan Database & User MySQL Terpisah

Buat database khusus baru bernama poshub_accounting dan user database terisolasi:

Terminal VPS (SSH) 
sudo mysql -u root -p

Jalankan query SQL berikut:

MySQL CLI 
-- 1. Buat Database Khusus POSHUB
CREATE DATABASE poshub_accounting CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci;

-- 2. Buat User Khusus POSHUB
CREATE USER 'poshub_user'@'localhost' IDENTIFIED BY 'PoshubStrongPass2026!';

-- 3. Berikan Hak Akses Penuh HANYA pada Database POSHUB
GRANT ALL PRIVILEGES ON poshub_accounting.* TO 'poshub_user'@'localhost';

-- 4. Terapkan Perubahan
FLUSH PRIVILEGES;

-- 5. Keluar dari MySQL
EXIT;

7. Konfigurasi Nginx Server Block (Virtual Host)

Terminal VPS: sudo nano /etc/nginx/sites-available/poshub.internatechtion.my.id 
server {
    listen 80;
    listen [::]:80;
    server_name poshub.internatechtion.my.id;

    root /var/www/poshub/public;
    index index.php index.html;

    # Limit Upload Size (50 MB)
    client_max_body_size 50M;

    # Security Headers
    add_header X-Frame-Options "SAMEORIGIN";
    add_header X-Content-Type-Options "nosniff";
    add_header X-XSS-Protection "1; mode=block";

    location / {
        try_files $uri $uri/ /index.php?$query_string;
    }

    # Static Assets Caching
    location ~* \.(jpg|jpeg|png|gif|ico|css|js|svg|webp|woff|woff2|ttf|eot)$ {
        expires 30d;
        add_header Cache-Control "public, no-transform";
        access_log off;
    }

    # Pass PHP scripts to FastCGI (PHP 8.2-FPM)
    location ~ \.php$ {
        include snippets/fastcgi-php.conf;
        fastcgi_pass unix:/var/run/php/php8.2-fpm.sock;
        fastcgi_param SCRIPT_FILENAME $realpath_root$fastcgi_script_name;
        include fastcgi_params;
        fastcgi_read_timeout 300;
    }

    # Block Hidden Files
    location ~ /\.(?!well-known).* {
        deny all;
    }
}

Aktifkan virtual host dan reload Nginx:

Terminal VPS (SSH) 
sudo ln -s /etc/nginx/sites-available/poshub.internatechtion.my.id /etc/nginx/sites-enabled/
sudo nginx -t
sudo systemctl reload nginx

10. Konfigurasi Queue Worker & Cron Job Scheduler

Agar fitur antrean WhatsApp, notifikasi stok, dan jadwal backup otomatis berjalan di background:

Terminal VPS: sudo nano /etc/supervisor/conf.d/poshub-worker.conf 
[program:poshub-worker]
process_name=%(program_name)s_%(process_num)02d
command=php /var/www/poshub/artisan queue:work --sleep=3 --tries=3 --max-time=3600
autostart=true
autorestart=true
stopasgroup=true
killasgroup=true
user=www-data
numprocs=2
redirect_stderr=true
stdout_logfile=/var/www/poshub/storage/logs/worker.log
stopwaitsecs=3600
Terminal VPS (SSH) 
sudo supervisorctl reread
sudo supervisorctl update
sudo supervisorctl start poshub-worker:*

# Tambahkan Cron Job Laravel Scheduler
(crontab -l 2>/dev/null; echo "* * * * * cd /var/www/poshub && php artisan schedule:run >> /dev/null 2>&1") | crontab -
