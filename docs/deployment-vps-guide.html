2. Setup DNS Record di Rumahweb

Karena domain internatechtion.my.id dibeli di Rumahweb, Anda harus mengarahkan subdomain poshub ke alamat IP Publik VPS Domainesia Anda.

1
Login ke ClientZone Rumahweb
Buka clientzone.rumahweb.com → Masuk ke menu Domains → Pilih domain internatechtion.my.id → Klik DNS Management (atau Zone Editor).
2
Tambahkan A-Record Subdomain Baru
Buat DNS Record baru dengan parameter berikut:
Record Type Host / Subdomain Name Target / IP Address TTL
A Record poshub 103.xxx.xxx.xxx (Masukkan IP Publik VPS Domainesia Anda) 14400 (atau Auto)
3
Verifikasi Propagasi DNS
Tunggu 2–10 menit, lalu uji di terminal komputer Anda apakah domain sudah terhubung ke IP VPS:
Command Prompt / Terminal 
ping poshub.internatechtion.my.id
Jika muncul balasan IP VPS Domainesia Anda, berarti DNS sudah 100% terhubung!

3. Pembuatan Database & User MySQL Terpisah

Login ke SSH VPS Domainesia Anda menggunakan terminal (Putty / Terminal Windows / MacOS):

Terminal SSH 
ssh root@IP_VPS_DOMAINESIA

Masuk ke MySQL server dan buat database khusus POSHUB (terpisah dari database CRM):

MySQL Root Console 
mysql -u root -p

Jalankan perintah SQL berikut untuk membuat database dan user khusus POSHUB:

SQL Commands (Isolated Database) 
-- 1. Buat database baru khusus POSHUB
CREATE DATABASE poshub_accounting CHARACTER SET utf8mb4 COLLATE utf8mb4_unicode_ci;

-- 2. Buat user database baru khusus POSHUB (Ganti PasswordSangatKuat123! dengan password Anda)
CREATE USER 'poshub_user'@'localhost' IDENTIFIED BY 'PasswordSangatKuat123!';

-- 3. Berikan hak akses penuh hanya pada database poshub_accounting
GRANT ALL PRIVILEGES ON poshub_accounting.* TO 'poshub_user'@'localhost';

-- 4. Terapkan perubahan
FLUSH PRIVILEGES;

-- 5. Keluar dari MySQL
EXIT;

4. Upload & Isolasi Folder Aplikasi di VPS

Buat direktori khusus /var/www/poshub di VPS Domainesia:

Bash Command (VPS SSH) 
# Buat folder khusus poshub
sudo mkdir -p /var/www/poshub

# Berikan izin sementara untuk upload
sudo chown -R $USER:$USER /var/www/poshub
Cara Upload File:
Anda dapat mengupload seluruh file project POSHUB ke /var/www/poshub menggunakan FileZilla (SFTP), SCP, atau via Git Clone.

Setelah file selesai diupload, jalankan instalasi dependensi dan perizinan hak akses:

Bash Command (Setup Dependency & Permission) 
cd /var/www/poshub

# 1. Install dependensi composer (jika belum ada folder vendor)
composer install --no-dev --optimize-autoloader

# 2. Atur izin akses aman untuk storage dan bootstrap/cache
sudo chown -R www-data:www-data /var/www/poshub
sudo chmod -R 755 /var/www/poshub
sudo chmod -R 775 /var/www/poshub/storage
sudo chmod -R 775 /var/www/poshub/bootstrap/cache

6. Konfigurasi Nginx Server Block (Virtual Host Terpisah)

Buat file konfigurasi Nginx baru untuk domain poshub.internatechtion.my.id tanpa mengganggu konfigurasi Nginx CRM yang sudah ada:

Bash Command 
sudo nano /etc/nginx/sites-available/poshub.internatechtion.my.id

Tempelkan konfigurasi server block Nginx optimal berikut:

/etc/nginx/sites-available/poshub.internatechtion.my.id 
server {
    listen 80;
    server_name poshub.internatechtion.my.id;
    root /var/www/poshub/public;

    add_header X-Frame-Options "SAMEORIGIN";
    add_header X-Content-Type-Options "nosniff";
    add_header X-XSS-Protection "1; mode=block";

    index index.php index.html;
    charset utf-8;

    # Optimalisasi Upload File & Gambar Produk
    client_max_body_size 64M;

    location / {
        try_files $uri $uri/ /index.php?$query_string;
    }

    location = /favicon.ico { access_log off; log_not_found off; }
    location = /robots.txt  { access_log off; log_not_found off; }

    error_page 404 /index.php;

    # FastCGI PHP-FPM Handler (Sesuaikan versi PHP, misal: php8.1-fpm / php8.2-fpm)
    location ~ \.php$ {
        fastcgi_pass unix:/var/run/php/php8.1-fpm.sock;
        fastcgi_param SCRIPT_FILENAME $realpath_root$fastcgi_script_name;
        include fastcgi_params;
        fastcgi_hide_header X-Powered-By;
    }

    location ~ /\.(?!well-known).* {
        deny all;
    }
}

Aktifkan virtual host dan reload Nginx:

Bash Command 
# 1. Aktifkan symlink ke sites-enabled
sudo ln -s /etc/nginx/sites-available/poshub.internatechtion.my.id /etc/nginx/sites-enabled/

# 2. Uji apakah konfigurasi Nginx bebas error
sudo nginx -t

# 3. Reload Nginx (Aplikasi CRM tetap berjalan lancar tanpa terhenti)
sudo systemctl reload nginx

7. Setup SSL HTTPS Gratis (Certbot Let's Encrypt)

Pasang sertifikat SSL TLS/HTTPS gratis otomatis menggunakan Certbot:

Bash Command 
sudo certbot --nginx -d poshub.internatechtion.my.id
Certbot akan otomatis memperbarui konfigurasi Nginx menjadi port 443 (HTTPS) dan mengaktifkan pengalihan otomatis HTTP ke HTTPS (*Auto Redirect*). Sertifikat akan diperpanjang otomatis setiap 90 hari.
